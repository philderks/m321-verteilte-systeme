# Timeout pattern: service-01 Feign calls

`src/main/resources/application.properties` sets `spring.cloud.openfeign.client.config.service-01.readTimeout=250` (milliseconds). This limits how long service-02 waits for response data from service-01 on its existing Feign `BooksClient` (`GET /books` and `POST /books`). It does not change the separate RestTemplate `/call` path, add a fallback, or alter successful responses. A timed-out Feign call raises `RetryableException` with a socket read-timeout cause. This bounds waiting but does not repair an unhealthy service.

Run `./mvnw -Dtest=BooksClientTimeoutTest test` to observe the deterministic local HTTP-stub test. The stub delays a `GET /books` response for 1 second; before configuring the 250 ms timeout, this test failed because the call succeeded after the delay. With the timeout, the same call throws a Feign `RetryableException` caused by `SocketTimeoutException`. A separate test exercises ordinary `GET` and `POST` through the real configured Feign client and verifies successful JSON decoding/encoding. The test disables Eureka and points Feign to its loopback stub, so no other services need to run. Run `./mvnw verify` for the complete service-02 suite.
